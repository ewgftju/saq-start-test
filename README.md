# SAQ — Стартовая страница

Единая стартовая страница с семью разделами SAQ.

## Файлы

- `index.html` — структура страницы.
- `styles.css` — оформление и адаптивная сетка.
- `app.js` — карточки, адреса модулей и сворачивание меню.

Переходы в ЭВГА, СВА, профилактический контроль и СУР подключены к действующим макетам Vercel. Для возражений, аналитики и ОБМ пока показывается уведомление об отсутствии подключённого адреса.

## Развёртывание

Статический сайт, установка зависимостей и сборка не требуются.
Vercel: проект `saq-start-test`, Framework Preset `Other`, Output Directory `.`.

Логотип и шрифт используются с существующего стенда SAQ.
